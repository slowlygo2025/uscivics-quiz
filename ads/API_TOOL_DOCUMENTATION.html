USCivics Quiz — Google Ads API Tool Documentation

Internal documentation for Google Ads API Basic access review · August 2026

Internal only Search campaigns Single Ads account

This document describes an API tool operated solely for our own Google Ads account. It is not a multi-client SaaS and is not sold to third parties.

1. Product & company

USCivics Quiz (https://uscivics-quiz.com) is an independent free study website for the USCIS naturalization civics and English tests (2008 and 2025 versions). Core practice remains free; monetization is primarily consent-based advertising, with optional low-cost study upgrades possible later. We are not affiliated with USCIS and are not a law firm.

2. What the API tool does

A private Node.js operations toolkit in our application repository. It authenticates with OAuth 2.0 and our developer token, then manages Search campaigns for a single Google Ads customer ID.

Capability Status
Create Search campaign + daily budget Implemented (created PAUSED)
Create ad groups, keywords, responsive search ads Implemented (PAUSED)
Geo targeting (United States) + language (English) Implemented
Campaign-level negative keywords Implemented
Final URLs with UTM parameters to our landings Implemented
List accessible customers / credential checks Implemented
OAuth helper to obtain refresh token Implemented
Display, Performance Max, Video, Shopping, App Not supported
Manage ads for other advertisers / resell API access Not supported

3. Intended audience

  • API users: only our internal marketing/ops operators using our Google Cloud project and Ads account. No external developers or clients call the API through us.
  • Ad click audience: lawful permanent residents preparing for the U.S. citizenship interview, sent to free landings (N-400 filing date guide, 65/20 senior path, all 128 questions, practice simulation).

4. Architecture

Component Role
secrets/google-ads.env Local credentials (never committed to git)
scripts/gads-oauth.mjs One-time OAuth refresh token via localhost redirect
scripts/gads-check.mjs Validate required environment variables
scripts/gads-list-accounts.mjs listAccessibleCustomers
scripts/gads-create-campaign.mjs mutateResources — budget, Search campaign, criteria, ad groups, keywords, RSA (all PAUSED)
ads/google-ads-editor-import.csv Human-review / Editor fallback (Paused)
google-ads-api (npm) Client library for Google Ads API

Flow: OAuth → Customer(customer_id) → atomic mutateResources creating a PAUSED Search structure for operator review before any enablement in the Google Ads UI.

6. Compliance notes

  • Landings and ad copy present an independent study tool; not USCIS.
  • Website uses HTTPS; marketing cookies load only after consent.
  • Tool does not automate click fraud, unauthorized scraping of other accounts, or bulk account creation.
  • Developer token and OAuth credentials are used only for our authorized customer account(s).
  • Campaigns/ad groups/ads/keywords are created in PAUSED state until a human enables them after review.

7. Operator commands

Command Action
npm run gads:check Verify credentials
npm run gads:oauth Obtain refresh token
npm run gads:accounts List accessible customer IDs
npm run gads:create-campaign Create Search structure PAUSED (requires Basic developer-token access on production accounts)
